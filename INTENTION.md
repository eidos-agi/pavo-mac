# INTENTION — Pavo Mac

Load-bearing.

1. Pavo Mac is a **host**, not a second transcription engine. Pavo CLI remains the intelligence plane.
2. The pack is the file. UI is a view.
3. Plaud tokens stay in `~/.plaud/`. This repo never stores OAuth.
4. RSVP is not attendance. Speaker labels are not identity.
5. Agents may **propose**. Humans **bind**.
6. Media bytes never live under `artifacts/`.
7. OANF is a draft sibling of OMF. Until `eidos-agi/prim.oanf` exists, packs are OKF-shaped private convention.
8. Same sha256 + same Plaud id = skip. Force is explicit.
9. Mock is the default until a real adapter is swapped behind `PlaudClient`.
